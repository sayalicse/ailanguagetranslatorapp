# 📞 AI Language Translator App

## 📌 Description

The AI Language Translator App is an Android-based application designed to eliminate language barriers during voice communication.
It enables real-time speech translation during calls by converting spoken language into text, translating it, and delivering the output as speech.
The integration of Firebase ensures real-time data handling, while Agora enables seamless voice communication.

---

## 🚀 Features

* 🎙️ Real-time voice communication using Agora
* 🌐 Live language translation during calls
* 🔊 Speech-to-text and text-to-speech conversion
* ⚡ Fast and efficient real-time processing
* 🔥 Firebase integration for real-time data handling
* 📱 User-friendly Android interface

---

## 🛠️ Technologies Used

* 📱 Frontend: Java (Android), XML
* 🔥 Backend/Database: Firebase (Realtime Database / Firestore)
* 📡 Communication: Agora SDK
* 🎤 Speech Processing: Speech Recognition & Text-to-Speech APIs

---

## ⚙️ How It Works

1. User initiates a voice call using Agora
2. Speech is captured in real-time
3. Voice is converted into text
4. Text is translated into the target language
5. Translated text is converted back into speech
6. Output is delivered instantly to the receiver
